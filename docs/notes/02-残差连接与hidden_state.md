本篇回答两个问题：

1. $h = x + \text{Attn}(\text{Norm}(x))$ 为什么叫"残差连接"？这个名字怎么理解？
2. 层与层之间传递的东西本质是什么？为什么叫 `hidden_state`？

---

## 第一部分：残差连接

### 1.1 先纠正一个常见误解：残差不是那个 $x$

直觉上容易以为"保留下来的 $x$ 就是残差"。其实正好相反：

$$
h \;=\; \underbrace{x}_{\text{捷径（shortcut）}} \;+\; \underbrace{\text{Attn}(\text{Norm}(x))}_{\text{残差（residual）}}
$$

- 直接加过去的 $x$，叫**捷径连接**（shortcut connection）、**跳跃连接**（skip connection）或**恒等映射**（identity mapping）；
- 子层算出来的 $\text{Attn}(\text{Norm}(x))$，才是**残差**；
- "残差连接"指的是**整个结构**：因为有了这条捷径，子层被迫只学残差。

### 1.2 "残差"这个词从哪来

"残差"是统计学术语，指**实际值与基准值之间的差**。比如线性回归里，残差 = 观测值 − 拟合值，也就是"模型没解释掉、还剩下的那部分"。

这个名字是 He et al. 2015 在 ResNet 论文（*Deep Residual Learning for Image Recognition*）中提出的。思路是：

- 假设我们希望某一层实现映射 $H(x)$；
- 普通网络让这一层直接去拟合 $H(x)$；
- ResNet 改为让这一层去拟合 $F(x) = H(x) - x$，也就是**"目标输出"与"输入"之差**；
- 然后把输入加回来：$H(x) = x + F(x)$。

$F(x)$ 就是"在输入基础上还差多少"，即残差。**这个名字描述的是子层学习的对象，而不是那条捷径。**

### 1.3 为什么要让子层只学"差值"

ResNet 论文发现了一个反常现象：**56 层的普通网络，训练误差比 20 层的还高**。这不是过拟合，因为训练集上的误差就更高。

按理说，56 层网络至少可以做到和 20 层一样好：前 20 层照抄，后 36 层什么都不做（恒等映射）。但实验表明，让一堆"线性层 + 非线性"去精确拟合恒等映射 $H(x)=x$，优化器很难找到这样的解。

残差结构把这个难题变简单了：

| | 要实现"这一层什么都不做" | 要实现"做一点小修改" |
|---|---|---|
| 普通结构 $H(x)$ | 权重必须精确拟合恒等映射，很难 | 要在恒等映射附近精确调整，很难 |
| 残差结构 $x + F(x)$ | 只要 $F(x)=0$，权重趋向 0 即可，很容易 | 只要学一个小的 $F(x)$，很容易 |

一个类比是**修改文稿**：普通结构是每一层都把整篇文章重写一遍；残差结构是每一层在原稿上**加批注**。不需要修改时不写批注就行，原稿始终保留。

### 1.4 放到 Transformer 里：每个子层输出的是"增量"

在 MiniMind 里，每个子层的输出都是一个**增量** $\Delta$，加到主干上：

```python
hidden_states += residual                                                          # x + ΔAttn
hidden_states = hidden_states + self.mlp(self.post_attention_layernorm(hidden_states))  # h + ΔFFN
```

把 8 层展开：

$$
x_8 \;=\; x_0 \;+\; \sum_{l=1}^{8}\big(\Delta^{\text{Attn}}_l + \Delta^{\text{FFN}}_l\big)
$$

这带来两个结构上的保证：

**① 信息不会被覆盖。** 最初的 $x_0$（词嵌入）作为一个加法分量，**原封不动地存在于每一层**。后面的层只能往上添加内容，无法擦除前面的内容。

**② 梯度有一条直通路径。** 对第 $l$ 层的输入求导：

$$
\frac{\partial x_L}{\partial x_l} \;=\; I \;+\; \sum_{k \ge l}\frac{\partial \Delta_k}{\partial x_l}
$$

恒等矩阵 $I$ 保证了：无论中间各层的导数是大是小，loss 的梯度都能原样传回任何一层。

### 1.5 实验：把残差去掉会怎样

`exp3_residual.py` 在同一个随机初始化的 MiniMind 上，对比原版 Block 和去掉残差的 Block：

```
有残差：h = x + Attn(Norm(x));  x' = h + FFN(Norm(h))
无残差：h =     Attn(Norm(x));  x' =     FFN(Norm(h))
```

逐层测四个量：
- **与 x0 相似度**：当前 hidden_state 与第 0 层输入（词嵌入）的余弦相似度
- **位置间相似度**：同一句话中不同位置的向量两两之间的平均余弦相似度。越接近 1，说明所有 token 被"糊成"了同一个向量
- **原 token 可恢复率**：用嵌入矩阵给当前向量打分，最高分是不是输入的那个 token
- **梯度范数**：loss 对该层输入的梯度大小

#### 8 层（MiniMind 默认）

每格左边是有残差，右边是无残差：

| l | 与 x0 相似度 | 位置间相似度 | 原 token 可恢复率 | 梯度范数 |
|---|---|---|---|---|
| 0 | 1.000 / 1.000 | 0.000 / 0.000 | 100% / 100% | 1.97e-01 / 3.91e-01 |
| 1 | 0.103 / **0.000** | 0.149 / 0.113 | 22.7% / **0.0%** | 9.84e-03 / 3.19e-02 |
| 2 | 0.065 / 0.003 | 0.307 / 0.470 | 4.3% / 0.0% | 5.88e-03 / 2.10e-02 |
| 4 | 0.039 / −0.003 | 0.512 / 0.653 | 0.8% / 0.0% | 3.86e-03 / 1.03e-02 |
| 8 | 0.025 / 0.000 | 0.637 / 0.787 | 0.0% / 0.0% | — |

#### 32 层（加深后）

| l | 与 x0 相似度 | 位置间相似度 | 梯度范数 |
|---|---|---|---|
| 0 | 1.000 / 1.000 | 0.000 / 0.000 | 1.60e-01 / **7.54e+02** |
| 4 | 0.040 / −0.002 | 0.502 / 0.673 | 3.00e-03 / 2.25e+01 |
| 8 | 0.026 / 0.000 | 0.643 / 0.803 | 2.10e-03 / 5.90e+00 |
| 16 | 0.015 / −0.000 | 0.742 / 0.986 | 1.56e-03 / 3.38e-01 |
| 24 | 0.010 / 0.000 | 0.773 / **1.000** | 1.35e-03 / 2.42e-02 |
| 28 | 0.011 / −0.001 | 0.784 / **1.000** | 1.28e-03 / 6.24e-03 |
| 32 | 0.009 / −0.000 | 0.796 / **1.000** | — |

#### 结论

**① 没有残差，原始 token 信息第一层就丢光了。** 无残差时，第 1 层之后与 $x_0$ 的相似度就是 0，原 token 可恢复率也是 0。有残差时，$x_0$ 作为加法分量一直保留着，相似度始终为正。

**② 没有残差，深层网络会让所有 token 变成同一个向量。** 32 层无残差时，位置间相似度在第 24 层达到 1.000：句子里每个位置的向量**完全一样**，模型无法再区分任何 token。注意力在本质上是加权平均，反复平均就会把差异抹平，这个现象称为**秩坍缩**（rank collapse，Dong et al. 2021, *Attention is Not All You Need*）。有残差时，相似度停在 0.8 左右，各位置仍然可以区分。

**③ 没有残差，梯度大小随深度剧烈变化。** 32 层无残差时，从顶层到底层，梯度从 6e-3 增长到 754，**相差约 10 万倍**：底层梯度爆炸，顶层相对极小，用同一个学习率不可能同时照顾好所有层。有残差时，第 4 层到第 28 层的梯度只相差约 2.3 倍，非常平稳。（第 0 层的梯度偏大，是因为嵌入向量的范数很小，RMSNorm 反向时会放大梯度，有残差和无残差都存在这个现象。）

#### 实验中和预期不符的地方（如实说明）

- **8 层时，去掉残差并没有出现梯度消失。** 原因是 MiniMind 每个子层前都有 RMSNorm，它本身就在调节梯度尺度（实验 1 已经展示过）。8 层太浅，残差对梯度的作用还看不出来；加深到 32 层，差距才变得非常明显。**网络越深，残差越不可或缺。**
- **有残差时，原 token 可恢复率在第 5 层之后也降到了 0。** 这是随机初始化的特点：嵌入向量范数只有约 0.56，而每个子层写入的增量范数约为 5，随机增量把原始信息"淹没"了。$x_0$ 在数学上仍然存在，只是在这种比例下，靠简单打分已经认不出来。训练后，模型会学会调节各子层写入的大小和方向。因此这一列只在"有残差 vs 无残差"的对比上有意义：无残差时是**彻底丢失**，有残差时是**仍然存在、可以被学会利用**。

### 1.6 小结

> **残差连接 = 捷径 $x$ + 子层学习的残差 $F(x)$。**
> "残差"指的是子层学习的"输出与输入之差"，不是被保留的 $x$。
> 这个结构让每个子层只需学一个"增量"：不需要时输出 0 就行，需要时做小修改。它保证了**原始信息不会被覆盖**、**梯度有直通路径**，网络越深作用越关键。

## 第二部分：hidden_state

### 2.1 名字从哪来

`hidden_state` 由两个词组成，分别来自两段历史：

**"hidden"：来自"隐藏层"。** 在最早的多层感知机里，网络分为三部分：

| | 输入层 | 隐藏层 | 输出层 |
|---|---|---|---|
| 外界能否看到 | 能，是我们给的数据 | **不能** | 能，是模型的预测 |
| 有没有标签规定它该是什么 | — | **没有** | 有（训练目标） |

中间层之所以"隐藏"，有两层含义：一是它不直接出现在输入或输出里，外界观察不到；二是**没有任何人规定它应该是什么值**。它的含义完全由训练过程自己决定，只要最终输出对就行。

**"state"：来自 RNN 的"隐状态"。** RNN 处理序列时，会维护一个向量 $h_t$，每读一个词就更新一次：$h_t = f(h_{t-1}, x_t)$。这个向量记录了"读到目前为止的状态"，所以叫隐状态（hidden state）。

Transformer 出现后，HuggingFace 等框架沿用了这个名字，把**每一层输出的中间表示**都叫 `hidden_states`。比如调用模型时传 `output_hidden_states=True`，就会返回 embedding 输出加上每一层输出共 $L+1$ 个张量。

### 2.2 Transformer 的 hidden_state 和 RNN 的有什么不同

名字一样，但"状态"沿着不同的方向传递：

| | RNN | Transformer |
|---|---|---|
| 状态沿什么方向传递 | **时间**：第 $t$ 个词 → 第 $t+1$ 个词 | **深度**：第 $l$ 层 → 第 $l+1$ 层 |
| 每一步有几个状态 | 1 个向量，概括整个历史 | 每个位置 1 个，共 $T$ 个 |
| 词与词之间怎么交流 | 只能通过这个状态逐步传递 | 通过注意力直接互看 |
| 形状 | `[B, 768]` | `[B, T, 768]` |

RNN 必须把整段历史压缩进一个向量；Transformer 的每个位置都有自己的状态，并且可以通过注意力直接读取其他位置的状态。

### 2.3 层与层之间传的到底是什么

在 MiniMind 里，层与层之间传递的是一个形状为 `[B, T, 768]` 的张量：**每个位置一个 768 维向量**。它就是第 01 篇里说的**残差流**在某一层的内容，"hidden_state"和"残差流"是同一个东西的两种叫法。

这个向量的本质可以概括为：

> **第 $t$ 个位置的 hidden_state = 模型此刻对"这个 token 在这句话里是什么意思"的理解，以及对"下一个 token 是什么"的推测。**

它在逐层传递中不断变化：

| 阶段 | hidden_state 里主要有什么 | 依据 |
|---|---|---|
| 第 0 层（Embedding 输出） | 只有**这个词本身**的含义。查表得到，与上下文无关："苹果"无论出现在哪句话里，向量都一样 | `embed_tokens` 是纯查表 |
| 中间层 | 逐渐融入**上下文**：多义词被消歧（水果还是公司），代词找到指代对象（"it" → "animal"），并通过 FFN 调取相关知识 | 注意力搬运上下文，FFN 调取记忆 |
| 最后几层 | 越来越接近**对下一个词的预测** | 最后一层的输出会直接送进 lm_head 打分 |

最后一点值得强调。第 $t$ 个位置的最终向量要用来预测第 $t+1$ 个 token（第 01 篇 8.1 节的错位交叉熵）。所以从底层到顶层，这个位置的向量在逐渐从"**我是谁**"转变为"**下一个是谁**"。

这个过程可以用 **logit lens** 观察（nostalgebraist 2020）：把**中间层**的 hidden_state 直接送进最终 Norm 和 lm_head，看看"如果在这一层就停下来，模型会预测什么"。在训练好的模型上，通常能看到预测随层数逐渐变得清晰、准确。我们的仓库里还没有训练好的权重，等训练或下载权重之后可以做这个实验。

### 2.4 为什么说它是"隐藏的"：没有人规定它的含义

768 个维度中，没有哪一维被规定为"表示词性"或"表示情感"。训练的唯一要求是：**最终 lm_head 读出来的预测要对**。至于中间怎么表示、每一维代表什么，全由模型自己决定。

研究发现，模型倾向于用**向量空间中的方向**来表示概念（线性表示假说）。768 维的空间里可以容纳远多于 768 个近似正交的方向，所以一个 hidden_state 可以同时叠加很多信息。这也是为什么 hidden_state 很难直接解读，"可解释性"成为了一个专门的研究领域。

### 2.5 代码里的 `hidden_states` 变量

在 `MiniMindBlock.forward` 中，同一个变量名被反复使用：

```python
def forward(self, hidden_states, ...):            # 第 l 层的输入：x_l
    residual = hidden_states
    hidden_states, present_key_value = self.self_attn(...)   # 此刻是 Attn 的输出 Δ（还不是主干！）
    hidden_states += residual                              # 此刻是中间状态 h = x_l + Δ
    hidden_states = hidden_states + self.mlp(...)          # 此刻是第 l 层的输出：x_{l+1}
    return hidden_states, present_key_value
```

这里有个容易混淆的地方：第二行之后，`hidden_states` 暂时装的是注意力的输出（增量 $\Delta$），而不是主干；加上 `residual` 之后才变回主干。代码为了简洁复用了变量名，读的时候要分清每一刻它代表什么。

另外，`MiniMindForCausalLM` 返回的 `hidden_states` 字段（`:258`）是**经过最终 RMSNorm 之后**的最后一层输出，也就是送进 lm_head 之前的那个向量。

### 2.6 小结

> **hidden_state 是在层与层之间流动的 `[B, T, 768]` 张量，每个位置一个向量，也就是残差流在某一层的内容。**
> - "hidden"：它不是输入也不是输出，外界看不到，也没有标签规定它该是什么，含义由训练自己决定；
> - "state"：这个词沿用自 RNN 的隐状态，但在 Transformer 中，它沿着**深度**而不是时间传递；
> - 本质上，它是模型对"这个位置的 token 在上下文中的含义"的当前理解，并且越往上层越接近对下一个 token 的预测。

## 两个问题的联系

把两部分放在一起看：

- **hidden_state** 是在层间流动的那个向量；
- **残差连接** 规定了它的更新方式：每一层只能往上**添加**增量，不能覆盖。

所以 hidden_state 不是被每一层"重新生成"的，而是从词嵌入出发，被 16 个子层（8 层 × 2）逐步**累加修改**而成。这就是为什么第 01 篇里把它称为"残差流"：一条不断有支流汇入的河流。
